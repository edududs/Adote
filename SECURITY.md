# Segurança

## Como reportar

Não abra issue pública para falha de segurança. Use o
[relato privado do GitHub](https://github.com/edududs/Adote/security/advisories/new) ou escreva para
o mantenedor pelo e-mail do perfil no GitHub, com:

- o que a falha permite e a quem;
- os passos para reproduzir;
- a versão (rodapé do menu ou `GET /saude/`).

Resposta em até 7 dias. A correção sai numa versão `PATCH`, e o relato é creditado no changelog se
você quiser.

## Versões cobertas

Só a última versão publicada recebe correção.

## O que já é garantido

O modelo de ameaça está em [docs/security.md](docs/security.md): o que se protege, contra quem, e
os riscos assumidos.
